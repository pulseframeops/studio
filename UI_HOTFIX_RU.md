# PulseFrame Studio Alpha 0.2.7 · UI Hotfix

## Исправлено

1. **Справка, Новый, Открыть, Сохранить:** устранён аварийный обрыв инициализации из-за обращения к удалённому `montage-hide-visualizer`. Убраны все три устаревших обращения.
2. **Retro:** плашки ALPHA / версии полностью скрыты, но видны в обычных Neon/Montagem.
3. **Иконка:** удалён чёрный квадратный фон вокруг оригинальной иллюстрации, пересобран Windows `.ico` и убрана цветная плитка в шапке приложения.
4. Добавлены автоматические тесты наличия элементов, к которым обращается скрипт.

## Что проверено

- 53 Node.js теста прошли.
- В Chromium проверены нажатия Справка/Поддержка, Новый, Открыть, Сохранить и переключение Retro/Neon.
- Самостоятельный HTML-предпросмотр успешно запускается и принимает нажатия на те же кнопки.
- `.pulseframe` сохраняется как JSON со схемой версии 2 и вновь открывается.

## Что остаётся проверить на твоём компьютере

- Нативные диалоги Открыть/Сохранить Electron (в Chromium проверены браузерные аналоги).
- Полный MP4-экспорт в десктопной сборке.
- Смена иконки в окне/панели задач Windows: иногда Windows кэширует предыдущий значок.

Распакуй архив в отдельную папку и запусти `RUN_WINDOWS.bat`. Сделай резервную копию важных проектов.
