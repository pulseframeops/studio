# PulseFrame Studio Alpha 0.2.8 · Retro TV & Pulsy Runner

## Новое в сборке

**Retro TV**
- Вместо стандартных Intro/Outro у Retro отдельные сцены: появление комнаты с телевизором TOSHIBA на тумбе (длительность 1–4 с), VHS-стилизованная информация об исполнителе и треке на экране, затем запуск выбранной живой Retro-сцены.
- Основной экран Retro: телевизор слева, обложка, спектр, исполнитель, название и выбор музыкальных платформ справа. Шумы VHS и scanlines генерируются локально. Обе сцены работают по таймкодам и участвуют в экспорте.
- За `outro.durationSec` до завершения (по умолчанию 10 с) изображение телевизора гаснет, затем печатается настраиваемая благодарность. **Режим рекомендаций:** две пустые рамки для YouTube; **режим площадок:** логотипы выбранных сервисов и сообщение про ссылки в описании.
- Напомним: сами рекомендации надо добавлять в YouTube Studio после публикации. YouTube допускает конечные заставки в пределах последних 5–20 с видео от 25 с. https://support.google.com/youtube/answer/6388789

**Pulsy Runner**
- По-прежнему скрытая игра `plsframe`, доступная после двух этапов Звездопада.
- Главная героиня: Pulsy Jessica. Отдельные PNG-спрайты с прозрачностью для idle / бега / прыжка / рывка, из оригинальной сгенерированной графики.
- Три уровня: Neon City, Circuit Factory, Sky Gardens. Параллакс, сменяющиеся декорации, враги, шипы, контрольные точки, плавающие платформы, кольца над проходимыми поверхностями, финишные порталы.
- Клавиши: ← → / A D, пробел (двойной прыжок), Shift (рывок), R (повтор), M (музыка).
- Три оригинальных зацикленных ретро-мелодии в WAV; музыка и звуки доступны офлайн.

**Совместимость:** формат `.pulseframe` по-прежнему `schemaVersion: 2`; новые настройки находятся исключительно в необязательном объекте `retro`. Не переименовываются существующие переходы и эффекты Neon/Montagem.

## Проверка и ограничения

`npm test` запускает автоматические регрессионные проверки. Для запуска программы нужна установленная среда Node.js и выполнение `npm install`, затем `npm start`, либо `RUN_WINDOWS.bat`. Для MP4 необходим FFmpeg, можно указать portable `ffmpeg.exe`.

Оффлайн HTML-предпросмотр показывает анимацию, но не создаёт MP4. Разрешение YouTube рекомендаций интерактивно вставляется только в самой YouTube Studio.

Сборка исходников остаётся Alpha; совместимость с любыми кодеками и полноэкранная производительность требуют проверки на реальном компьютере.
